# Алгоритмы и форматы

| Стандарт | Реализованные возможности |
|---|---|
| ГОСТ Р 34.12-2015 | Блочные шифры Магма и Кузнечик |
| ГОСТ Р 34.13-2015 | ECB, CTR, CBC, OFB, CFB, padding и OMAC |
| ГОСТ Р 34.11-2012 | Потоковые Стрибог-256 и Стрибог-512 |
| ГОСТ Р 34.10-2012 | Кривые ТК26, подпись, кодеки ключей и VKO-2012 |
| RFC 7836 / Р 1323565.1.017-2018 | KDF, KDF_TREE, CTR-ACPKM, ACPKM-Master, KExp15 и KImp15 |
| RFC 9058 / RFC 9059 | Аутентифицированное шифрование MGM |
| Устаревшие стандарты | ГОСТ 28147-89, ГОСТ Р 34.11-94 и CryptoPro key wrap |
| PKI и контейнеры | DER/ASN.1, PKIX, PKCS #8/#10/#12, сертификаты, CRL, CMS, CAdES-BES/T, RFC 3161 и RFC 4490 |

Подключайте наиболее узкий подходящий пакет:

```js
import { streebog512 } from "@gostcrypto/hash";
import { Kuznyechik } from "@gostcrypto/ciphers";
import { parseSignedData } from "@gostcrypto/cms";
```

Набор проверок основан на векторах RFC, ГОСТ и исходного Go-проекта. Методика
измерений и сравнение с другими JavaScript-реализациями приведены в разделе
[Производительность](../BENCHMARKS.md).
